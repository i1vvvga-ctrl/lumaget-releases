# Luma

Скачивайте видео и аудио. Загрузки и автообновления Luma.

## Windows
Скачайте `Luma-…-Windows-x64-Setup.exe` на странице [Releases](../../releases/latest) и запустите.

## Mac
Откройте «Терминал» и выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/i1vvvga-ctrl/lumaget-releases/main/install-mac.sh | bash
```

Скрипт сам выберет версию для вашего процессора (Apple Silicon или Intel), поставит Luma в «Программы» и откроет её. Чтобы обновиться, запустите ту же команду ещё раз.

Удалить: `rm -rf /Applications/Luma.app`
