# Luma — скачать видео и аудио на Windows и Mac

**Luma** — бесплатная программа для компьютера: вставьте ссылку, выберите качество и сохраните видео или звук. Без рекламы и расширений для браузера.

Сайт: **[lumavideo.app](https://lumavideo.app)** · Инструкции: [lumavideo.app/instrukcii](https://lumavideo.app/instrukcii/)

## Что умеет

- Видео до **4K и 8K** (если такое качество есть у ролика) и аудио: MP3, M4A, Opus
- **Плейлисты и каналы целиком**, пакеты ссылок (до 200 роликов)
- Скачивание **только нужного фрагмента** с предпросмотром
- Очередь, пауза, повтор, история, до 4 загрузок одновременно (больше с Pro)
- YouTube, VK, RuTube, TikTok, Vimeo, Twitch, Одноклассники, Дзен и другие сайты
- Светлая и тёмная темы, автообновления на Windows
- Всё нужное внутри: yt-dlp и ffmpeg уже в составе программы

## Windows

Скачайте `Luma-…-Windows-x64-Installer.exe` на странице [Releases](../../releases/latest) и запустите. Права администратора не нужны.

## Mac

Откройте «Терминал» и выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/i1vvvga-ctrl/lumaget-releases/main/install-mac.sh | bash
```

Скрипт сам выберет версию для вашего процессора (Apple Silicon или Intel), поставит Luma в «Программы» и откроет её. Чтобы обновиться, запустите ту же команду ещё раз.

Удалить: `rm -rf /Applications/Luma.app`
